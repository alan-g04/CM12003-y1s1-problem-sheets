# CM12003 Haskell Exercises

This repository contains a series of Haskell programming exercises for the CM12003 course. Each exercise focuses on different aspects of functional programming in Haskell.

## Structure

The exercises are organised into the following folders:

- **1-Haskell_Basics/**: Basic Haskell concepts and syntax.
- **2-Lists/**: Working with lists in Haskell.
- **3-RPN_calculator/**: Implementing a Reverse Polish Notation calculator.
- **4-Map_filter_comprehension/**: Using map, filter, and list comprehensions.
- **5-Input-output/**: Handling input and output in Haskell.
- **6-Noughts_and_crosses/**: Implementing a tic-tac-toe game.
- **7-Trees/**: Working with tree data structures.
- **8-Folds/**: Using fold functions in Haskell.

Each folder contains:
- A `.hs` file with the exercise code.
- An `_Answers.md` file with solutions and explanations.

## Prerequisites

- Haskell Platform or GHC (Glasgow Haskell Compiler) installed.
- Basic knowledge of functional programming concepts.

## How to Run

1. Navigate to the desired exercise folder.
2. Load the `.hs` file in GHCI: `ghci <filename>.hs`
3. Or compile with GHC: `ghc <filename>.hs` and run the executable.
